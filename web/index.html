01 / THE RULES

Every return counts.

Earn a point each time you return the ball. Miss it and lose a life. You start with ten — the last player standing wins.

02 / THE TWIST

A little extra in your corner.

Hit a power-up with the ball to claim it for the last player to return it. Change paddle size, ball speed, and more.

03 / THE CONTROLS

Pick up. Play. Repeat.

Use W / S or the on-screen controls. In solo and online modes, you can also drag on the court. Space pauses; Escape returns to the menu.
